SELECT
    l.*,
    s.*,
    lad.day_name,
    lr.responsibility,
    ud.start_date,
    ud.end_date,
    ud.reason
FROM availability_submissions s
JOIN lectors l
    ON l.id = s.lector_id
LEFT JOIN lector_available_days lad
    ON lad.submission_id = s.id
LEFT JOIN lector_responsibilities lr
    ON lr.submission_id = s.id
LEFT JOIN unavailable_dates ud
    ON ud.submission_id = s.id
WHERE s.monthly_form_id = 2
ORDER BY l.id;

Terminal 1 – Start backend
Open VS Code terminal and run:

1. Go to backend folder
cd ~/Desktop/ChurchBuddy/backend


2. Activate virtual environment
source .venv/bin/activate


3. Start FastAPI
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000


Backend running
Open: http://localhost:8000/docs
Terminal 2 – Start ngrok
Open a second terminal and run:
ngrok http 8000
